# Future Scope

- **Real-time monitoring API** — continuously audit live predictions via
  a REST endpoint with drift alerts.
- **Regulatory mapping** — map audit outputs to EU AI Act risk
  categories, US SR 11-7 model risk management, and ECOA/ADEA fair-lending
  tests.
- **Mitigation toolbox** — integrate Fairlearn reductions (Exponentiated
  Gradient, Grid Search) and post-processing to *fix* bias, not just flag it.
- **Broader model coverage** — text (LLM audits), images, and
  regression targets.
- **Explainability alternatives** — LIME, counterfactual explanations
  (DiCE), and natural-language feature attributions.
- **Multi-stakeholder views** — separate report layouts for engineers,
  executives, and regulators.
- **Dataset versioning + experiment tracking** — full audit trail for
  each model release.
